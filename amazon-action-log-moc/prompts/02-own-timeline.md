# Prompt 02 — Own listing action timeline

---

Using only OWN action log data already pasted (or normalized):

1. Build a chronological timeline per own ASIN.
2. Group bursts of edits that happened within 2 hours as a single “edit session”.
3. Call out high-impact changes: price, coupon, images, title, A+, inventory→OOS, suppression.
4. Note actor patterns (who changes what most).
5. Mark any change that still looks unfinished (e.g. title changed but images not updated).

Output:
- Per-ASIN timeline (timestamp → action → before → after → actor)
- Edit sessions summary
- Open risks on our side only (ignore competitors for this prompt)
